Cài đặt

Dashboard đăng nhập bằng tài khoản Google (OAuth, quyền chỉ đọc YouTube) để gọi YouTube Data API v3. Không cần API key.

  1. Vào Google Cloud Console và bật YouTube Data API v3.
  2. Ở Credentials → Create credentials → OAuth client ID, chọn loại Web application, thêm Authorized JavaScript origins: https://mindphoenix.xyz.
  3. Ở OAuth consent screen, nếu app đang ở chế độ Testing thì thêm email của bạn vào Test users.
  4. Tải file client_secret_….json về và chọn file đó bên dưới.
