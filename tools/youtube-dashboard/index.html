    Cài đặt

    Dashboard đăng nhập bằng tài khoản Google (OAuth, quyền chỉ đọc YouTube) để gọi YouTube Data API v3. Không cần API key hay quyền Analytics.

    Xem Chính sách bảo mật và Điều khoản dịch vụ trước khi kết nối tài khoản Google.

    1. Vào Google Cloud Console và bật YouTube Data API v3.
    2. Ở Credentials → Create credentials → OAuth client ID, chọn loại Web application, thêm Authorized JavaScript origins: https://mindphoenix.xyz.
    3. Ở OAuth consent screen, nếu app đang ở chế độ Testing thì thêm email của bạn vào Test users.
    4. Tải file client_secret_….json về và chọn file đó bên dưới.

    Chỉ cần đăng nhập Google một lần để xem số liệu công khai của tất cả kênh trong danh sách, không cần kết nối riêng từng kênh. Số subscribers có thể được YouTube làm tròn; kênh ẩn sub hoặc tải lỗi được đánh dấu riêng, không tính là 0 trong tổng.

    Báo cáo được lưu đệm trên trình duyệt trong 30 phút trước khi cần làm mới. Đăng xuất sẽ xóa cache và token đã lưu, giữ lại cài đặt.
